# 🚀 DevOps Assessment Platform

## 📌 Overview

The **DevOps Assessment Platform** is a full-stack web application designed to conduct chapter-based technical assessments. It helps evaluate knowledge across key DevOps domains like:

- DevOps Fundamentals  
- AWS  
- Docker  
- Kubernetes  

This project demonstrates **end-to-end DevOps implementation**, including development, containerization, CI/CD, and Kubernetes deployment.

---

## 🏗️ Architecture

User → Flask App → Docker → Kubernetes → GitHub Actions (CI/CD)

---

## ✨ Features

- 📚 Chapter-wise MCQ assessments  
- 🧠 Dynamic question handling (backend-driven)  
- 📊 Score calculation  
- 🎨 Modern UI/UX  
- 🐳 Docker support  
- ☸️ Kubernetes deployment  
- 🔄 CI/CD pipeline (GitHub Actions)  
- ❤️ Health check endpoint
